
# Tutorials and Workshops

This is a collection of small guides I put together for my students and workshop participants, mostly to answer questions that come up again and again during supervision or teaching.

Instead of explaining the same thing in every meeting, I try to write it down once here, so you can go through it at your own pace. That said, feel free to still ask me anything — these are just a starting point.

## What's inside

- **GitLab Tutorial** — a quick guide for ISBE students on setting up and using GitLab at TU/e
- **GitHub_tutorials** — how to anonymise a GitHub repo for double-blind paper submissions
- **Writing Articles** — templates and tips for academic writing, including a rebuttal template for reviewer responses
- **BIM-DigiTSS workshop** — materials from a workshop on BIM, ontologies, and AI for circular construction

## Using this

Everything here is free to use and adapt. If something is unclear, outdated, or missing, let me know — this repo grows over time as new questions come up.
