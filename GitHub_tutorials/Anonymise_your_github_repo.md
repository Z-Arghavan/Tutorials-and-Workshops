
# How to Anonymise a GitHub Repository using "Anonymous GitHub"


Anonymous GitHub creates an anonymised, read-only version of a public GitHub repository.

1. Make sure the repository is public.
2. Go to [Anonymous GitHub](https://anonymous.4open.science/anonymize).
3. Paste the URL of the GitHub repository.
4. Choose an anonymous name for the repository.
5. Generate the anonymous link.
6. Open the link in a private or incognito browser window.
7. Check that your name, username and profile are not visible.




When submitting a paper for double-anonymous peer review, sharing a normal GitHub repository can reveal your identity through your username, profile, commit history or repository content. The generated link can then be included in the anonymised manuscript.

Example:

```text
The source code and supporting materials are available through an anonymised repository at: [ANONYMISED REPOSITORY URL].
```
It may be useful to create a separate anonymised copy of the repository and remove identifying information from that version.
